# I18n — Internationalisation

`hamr/pkg/i18n` provides JSON-based translation files, CLDR plural rules,
`text/template` interpolation, RTL detection, and a Bundle that holds
per-locale Translators.

## Quick Start

```go
import "github.com/FyrmForge/hamr/pkg/i18n"
```

## Bundle

A `Bundle` loads all `*.json` files from a locale directory, validates them
against the default locale, and builds a `Translator` per locale.

```go
bundle, err := i18n.NewBundle(i18n.BundleConfig{
    LocaleDir:         "locales",
    DefaultLocale:     "en",
    FallbackToDefault: ptr.To(true),
})
```

| Field | Default | Description |
|-------|---------|-------------|
| `LocaleDir` | required | Directory containing `*.json` locale files |
| `DefaultLocale` | `"en"` | Locale code used as the source of truth |
| `FallbackToDefault` | `true` (nil = true) | Return default locale value for missing keys |

### Validation

`NewBundle` validates every non-default locale against the default:

- **Missing keys** — allowed; they fall back to the default locale at runtime.
- **Extra keys** — allowed; informational only.
- **Interpolation mismatches** — hard error. If `en.json` uses `{{.Name}}` but
  `fr.json` uses `{{.FirstName}}` for the same key, `NewBundle` returns an error.

### Querying the Bundle

```go
bundle.HasLocale("fr")           // true if "fr" is loaded
bundle.SupportedLocales()        // sorted list of loaded locale codes
bundle.DefaultLocale()           // "en"
bundle.Translator("fr")          // *Translator for "fr" (falls back to default)
```

### Region-tag resolution

`ResolveLocale` finds the best match for a code that may include a region tag:

```go
loc, ok := bundle.ResolveLocale("fr-FR") // ("fr", true) — matches base language
loc, ok := bundle.ResolveLocale("fr")    // ("fr", true) — exact match
loc, ok := bundle.ResolveLocale("xx")    // ("", false)  — no match
```

This is used internally by the locale middleware to resolve user preferences and
cookies that may contain region-tagged codes.

## Translator

Each locale has a `Translator` that resolves keys to translated strings.

### Plain keys

```go
tr := bundle.Translator("fr")
tr.T("app.title") // "Mon App"
```

### Interpolation

```go
tr.T("home.welcome", map[string]any{"Name": "Alice"})
// "Bienvenue, Alice !"
```

### Plurals

Pass an `int` as the first argument for plural resolution:

```go
tr.T("home.items", 1)  // "1 objet"
tr.T("home.items", 5)  // "5 objets"
```

`Count` is auto-injected into template data. Additional interpolation params
can follow:

```go
tr.T("inbox.messages", 3, map[string]any{"User": "Bob"})
```

### Fallback

When `FallbackToDefault` is enabled and a key is missing from a locale, the
default locale's translation is returned. If the key doesn't exist anywhere,
the raw key string is returned.

## JSON File Format

Locale files use nested JSON with dot-path keys:

```json
{
  "_meta": {
    "direction": "ltr",
    "displayName": "English"
  },
  "app": {
    "title": "My App"
  },
  "home": {
    "welcome": "Welcome, {{.Name}}!",
    "items": {
      "one": "{{.Count}} item",
      "other": "{{.Count}} items"
    }
  }
}
```

- Keys starting with `_` (like `_meta`) are skipped.
- Plural objects use CLDR category keys: `zero`, `one`, `two`, `few`, `many`, `other`.
- Interpolation uses Go `text/template` syntax: `{{.VarName}}`.

## Plural Rules

Built-in CLDR plural rules cover 30+ languages including English, French,
German, Spanish, Polish, Russian, Arabic, Japanese, Chinese, and more.

```go
i18n.RuleFor("fr")    // French: 0 and 1 → "one", rest → "other"
i18n.RuleFor("ar")    // Arabic: zero/one/two/few/many/other
i18n.RuleFor("ja")    // Japanese: always "other"
```

Register custom rules:

```go
i18n.RegisterRule("my-lang", func(n int) i18n.PluralCategory {
    if n == 1 { return i18n.One }
    return i18n.Other
})
```

## RTL Detection

```go
i18n.DirectionFor("ar")    // "rtl"
i18n.DirectionFor("ar-SA") // "rtl" (region tags supported)
i18n.DirectionFor("en")    // "ltr"
```

RTL languages: Arabic, Hebrew, Farsi, Urdu, Pashto, Sindhi, Yiddish, Kurdish.
Override per-locale via `_meta.direction` in the JSON file.

## Context Helpers

Retrieve the translator and locale set by the middleware:

```go
tr   := i18n.FromContext(c)           // *Translator (panics if not set)
loc  := i18n.LocaleFromContext(c)     // "fr"
dir  := i18n.DirectionFromContext(c)  // "ltr" or "rtl"
```

## Code Generation

`hamr locale gen` reads the default locale JSON and generates type-safe Go
accessor methods. See the [CLI reference](../cli.md#hamr-locale-gen) for details.

Keys starting with a digit (e.g. `2fa.title`) produce method names prefixed
with `X` to form valid Go identifiers (e.g. `X2faTitle`).

## API Reference

```go
// Bundle
type BundleConfig struct { ... }
func NewBundle(cfg BundleConfig) (*Bundle, error)
func (b *Bundle) Translator(locale string) *Translator
func (b *Bundle) SupportedLocales() []string

func (b *Bundle) ResolveLocale(code string) (string, bool)
func (b *Bundle) DefaultLocale() string

// Translator
func (t *Translator) T(key string, args ...any) string
func (t *Translator) Has(key string) bool
func (t *Translator) Locale() string
func (t *Translator) Direction() string

// Context
func FromContext(c echo.Context) *Translator
func LocaleFromContext(c echo.Context) string
func DirectionFromContext(c echo.Context) string

// Direction
func DirectionFor(lang string) string

// Plural rules
type PluralCategory string  // Zero, One, Two, Few, Many, Other
type PluralRule func(n int) PluralCategory
func RuleFor(lang string) PluralRule
func RegisterRule(lang string, rule PluralRule)
```
